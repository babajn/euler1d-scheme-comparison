標準設定：基本問題200セル。第I部の収束試験は50・100・200・400セル、第II～IV部は100・200・400・800セル。動画・追加実験・Shu–Osherは無効。

小規模追加実験：基本問題40セル、収束試験20・40・80セル、動画5フレーム。追加実験・動画を有効にし、EulerではShu–Osher40セル・数値参照解80/160セルも実行。1600/3200セルの参照計算はこの検証の対象外です。

スカラー11グループとEuler9グループの基本検証が通過しました。スカラー検証には正負の移流速度、CFL=1の厳密セル移動、数値流束の整合性、周期・流出境界の保存収支、Rankine–Hugoniot条件に基づく質量等価衝撃波位置、希薄波のエントロピー条件、厳密解の適用範囲、記録処理の中立性、収束次数を含みます。

二重希薄波におけるLW・Roe・MUSCL-Roeの負圧による停止は、数値スキームの失敗として記録されます。これはNotebookセルの実行エラーとは区別しています。補正なしRoeによるBurgersの膨張衝撃波も、意図した反例です。

これらは選択した問題・設定での検証であり、任意の初期条件に対する正確さ・安定性・正値性を保証するものではありません。
