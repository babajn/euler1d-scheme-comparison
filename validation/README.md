## 時間積分の収束試験

同じ半離散系に対する時間誤差を測定しています。連続方程式の厳密解との差は別に記録します。

- 問題：滑らかな周期エントロピー波。48セル、終了時刻0.2。
- 空間再構築：区分一定。流束ごとに空間離散化を固定。
- 時間刻み：40・80・160・320の等間隔ステップ数。
- 数値参照解：同じ格子・同じ流束のSSP-RK3、1280・2560ステップ。

160と320ステップから求めた観測時間次数の範囲（4流束）：

| 時間積分 | 観測次数 |
|:--|:--|
| 前進Euler | 1.00178–1.00215 |
| SSP-RK2 | 2.00026–2.00080 |
| SSP-RK3 | 3.00247–3.00300 |

2参照解間の密度差は約4.76e-12〜5.07e-12、各流束で測定した最小時間誤差に対する比は約0.0137でした。この比の小ささは参照解の確認であり、厳密な誤差保証ではありません。

## 追加実験と数値的な停止

第IV・V部については、追加実験・Shu–Osher・動画を有効にした小規模設定でも各11コードセルを実行し、セルエラーは0でした。基本40セル、空間収束20・40・80セル、Shu–Osher比較40セル・参照80/160セル、時間収束24セル・20/40/80/160ステップ・参照640/1280ステップ、動画5フレームです。

第IV部標準設定の144条件中11条件、第V部標準設定の105条件中3条件は、非物理的な状態を検出して停止しています。第IV部ではSodと二重希薄波の制限なし再構築、および二重希薄波のRoeが該当します。第V部では二重希薄波のRoe＋MUSCL-minmod（3時間積分法）が該当します。これらは教材が記録する数値的な失敗であり、Notebookセルの実行エラーではありません。

Shu–Osherの1600・3200セルの高解像度参照計算、すべての設定の組合せ、個々の利用者の実行環境は、この検証の対象外です。
